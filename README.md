## ⬡ Overview

**Madhu.dev** is the personal developer portfolio of **Madhu Shankar Kumar**, a B.Tech CSE student at GLA University specializing in Data Engineering, Java Development, and AI & Data Science.

This portfolio was crafted entirely from scratch — no Bootstrap, no Tailwind, no UI kits. Every animation, every layout, every interaction is hand-engineered using Vanilla CSS3 and TypeScript. The visual identity is built around a **Minimalist Matte Slate** theme: pitch-black backgrounds, matte graphite surfaces, metallic silver gradients, and glassmorphism card designs with floating ambient orbs.

> **Currently Open To:** Technical Work / Software Engineering roles.

## ◈ Responsive Design

```
Device                Width         Layout
─────────────────────────────────────────────────────────
Desktop (Full HD)     1440px+       3-col project grid · 4-col skills
Laptop                1024px–1440px 2-col project grid · 3-col skills
Tablet (Landscape)    768px–1024px  2-col adaptive · stacked timeline
Mobile (Standard)     375px–768px   Single column · hamburger nav
Mobile (SE / Tiny)    320px+        Compressed fluid layout via clamp()
```

**Fluid Typography:**
```css
font-size: clamp(0.9rem, 2.5vw, 1.1rem);   /* Body */
font-size: clamp(2rem, 5vw, 3.5rem);        /* Hero Headline */
```

**Grid Scaling:**
```css
/* Project Cards */
grid-template-columns: repeat(auto-fit, minmax(300px, 1fr));

/* Mobile Override */
@media (max-width: 480px) {
  grid-template-columns: 1fr;
}
```

## ◈ Getting Started

### Prerequisites

- **Node.js** `18+`
- **npm** `9+`

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/madhushankarkumar/madhu.dev.git

# 2. Navigate into the project
cd madhu.dev

# 3. Install dependencies
npm install
```

### Development

```bash
# Start local dev server (hot reload enabled)
npm run dev
```

> Opens at `http://localhost:5173`

### Build for Production

```bash
# TypeScript compile + Vite bundle
npm run build
```

> Outputs to `/dist` — ready for Vercel, Netlify, or any static host.

### Preview Production Build Locally

```bash
npm run preview
```

## ◈ Deployment

This project is deployed on **Vercel** with a custom `madhu.me` domain.

**Auto-deploy setup:**
1. Push to `main` branch
2. Vercel detects changes automatically
3. Runs `npm run build`
4. Deploys `/dist` to global edge CDN

**Vercel config (`vercel.json`):**
```json
{
  "buildCommand": "npm run build",
  "outputDirectory": "dist",
  "framework": null
}
```
